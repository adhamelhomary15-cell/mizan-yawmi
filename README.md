# ميزان يومي

تطبيق ويب يوزن اليوم بين الكلية والمذاكرة، الكورس، الشغل، الجيم، وحفظ القرآن، ومعاه مواعيد الصلاة في الجيزة.
بيتثبّت على الموبايل كتطبيق، وبيشتغل من غير نت.

## الملفات

- `src/planner.html`: كود التطبيق. أي تعديل في الجدول أو الشكل بيتعمل هنا.
- `tools/build.py`: بيبني النسخة اللي بتتنشر من `src/planner.html`، وبيحط المكتبات والخطوط جوه الصفحة عشان تشتغل أوفلاين.
- `index.html`, `manifest.webmanifest`, `sw.js`, والأيقونات: الملفات اللي GitHub Pages بينشرها. دي بتتعمل أوتوماتيك من الـ build، متعدّلش فيها بإيدك.

## التحديث

```
python3 tools/build.py
git add -A && git commit -m "..." && git push
```

بعد الـ push بدقيقة أو اتنين، التطبيق المتثبّت بياخد النسخة الجديدة أول ما يتفتح وفيه نت.

## الخصوصية

العلامات والمهام والكورسات اللي بتضيفها بتتحفظ على الجهاز بس (localStorage)، ومش بتترفع هنا.

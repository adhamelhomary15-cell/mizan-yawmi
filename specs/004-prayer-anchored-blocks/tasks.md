## Format: `[ID] [P?] [Story] Description`

- **[P]**: can run in parallel (different files, no dependency on an unfinished task)

## Phase 2: Foundational (blocks all stories)

**Purpose**: the pure layout rule, a validator that accepts the new element, and the check script. Nothing is wired to a screen yet, so app behavior is unchanged at the end of this phase.

- [ ] T004 Add `parseAnchor(el)` and anchor validation inside the existing block validator in `src/planner.html` (`checkBlocks`, about line 648): a block may have a sixth element (the validator today requires "2 to 5 items"; allow 2 to 6). The sixth element MUST be an object with exactly the keys `prayer` ("one of `fajr`, `dhuhr`, `asr`, `maghrib`, `isha`"), `dir` ("`before` or `after`") and `min` ("integer 0 to 180"); anything else (not an object, unknown value, extra key, non-integer or out-of-range `min`) is an error with code `invalid` and the path `<day>.blocks[<i>].anchor` naming the field. An anchored block MUST NOT be the first or the last block of its list: error `invalid` at the block path. Keep the existing messages for every other case; a file with no sixth element behaves exactly as before.
- [ ] T005 Add the pure layout function in a marked block (`// start of anchor layout` ... `// end of anchor layout`) in `src/planner.html` before `blocksFor`, with no storage or DOM access: `layoutDay(list, prayerMinutes, START, END)` where `list` is the day's tuples, `prayerMinutes` is `{fajr, dhuhr, asr, maghrib, isha}` in minutes since midnight or `null`. Follow [data-model.md](data-model.md): no anchors gives today's layout and `notice = null`; `prayerMinutes` null or the anchored prayer not a finite number gives fixed times and `notice = 'unavailable'`; otherwise `computed = Math.round((prayer + sign * min) / 5) * 5` (add 1440 when below `START`), `delta = computed - fixedStart`, one pass carrying `delta` (blocks after an anchored block shift by it until the next anchored block; an anchored block starts at `computed`), each block ends where the next starts and the last ends at `END`; fit rule: every block before an anchored block and the last block MUST be "at least 15 minutes" long, otherwise fixed times everywhere and `notice = 'nofit'`. Each returned block keeps `key = b[0] + '-' + b[1]` (the fixed start, never the computed start).
- [ ] T006 [P] Create `tools/check-anchors.js` (dev-only, Node, no dependencies), in the style of `tools/check-edit.js`: extract the layout block (and the anchor validation via `validateSettings`) from `src/planner.html`, and run synthetic checks: (a) a list with no anchors equals the plain layout for any prayer times; (b) an anchored block starts at prayer plus or minus minutes, rounded to 5 (`before` and `after`, each prayer); (c) day start and end are unchanged when it fits; (d) only the block before each anchored block and the last block change length; (e) two anchors in one list; (f) 15-minute floor: 15 fits, 14 gives `nofit` with all fixed times; (g) `null` prayer times and a missing prayer give `unavailable` with all fixed times; (h) a computed minute below `START` is treated as next day; (i) keys equal the fixed start plus category in every case; (j) input is not mutated. Exit 0 on pass, 1 on failure. Add `--self-test` with mutations that MUST be caught (floor changed, rounding removed, key uses computed start, last block not absorbing, notice not set).
- [ ] T007 Add anchor cases to the `--self-test` of `tools/check-settings.js`: unknown prayer, unknown direction, `min` of 200, `min` of 30.5, extra key, sixth element not an object, anchor on the first block, anchor on the last block, seven items; all rejected with the path of the block and code `invalid`; and a valid anchored block accepted. No example change yet.
- [ ] T008 Run `node tools/check-anchors.js`, `node tools/check-anchors.js --self-test`, `node tools/check-settings.js --self-test`, `node tools/check-edit.js`, `node tools/check-private.js`. Build with `PYTHONUTF8=1 python tools/build.py`, `git checkout` the icon files if Pillow re-rendered them, and run `node tools/check-parity.js --old $TEMP/baseline-planner.html --new src/planner.html --settings settings.example.json` expecting 0 differences (layout is not wired yet).

**Checkpoint**: layout rule and validator exist and are tested; nothing visible has changed. Commit as `feat(anchors): add layout rule, anchor validation and check script (004)`.
